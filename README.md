# ZeeTech // Tech — Premium Agency Portfolio

A high-performance, design-led digital product agency portfolio website built using the **PERN stack** (PostgreSQL, Express.js, React, Node.js), powered by **GSAP (ScrollTrigger)** and **Lenis** smooth scrolling.

---

## 🚀 Key Features & Interactions

- **Diagonal Project Rolling Wall**: Continuous diagonal collage of UI screens in the hero section.
- **Two-Way Infinite Marquee**: Seamless dual-directional logos without visible resets or jumps.
- **GSAP Project Card Stacking**: Deck-of-cards overlapping physics triggered on scroll.
- **Scroll-Triggered Counters**: Smooth animated number counting for agency statistics.
- **Lenis Smooth Scroll**: Buttery smooth scrolling linked with GSAP animation ticks.
- **RESTful API with Database Fallback**: Auto-falls back to structured mock data if PostgreSQL is not active during local development.

---

## 🛠️ Tech Stack

- **Frontend**: React 18, Vite, Tailwind CSS, GSAP 3 (ScrollTrigger), Lenis, Lucide Icons
- **Backend**: Node.js, Express.js, CORS, Morgan, Dotenv, PG (node-postgres)
- **Database**: PostgreSQL with modular SQL migration & seed files
